## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Decorative.</strong> <code>aria-hidden=&quot;true&quot;</code> — Skeleton
      itself carries no meaning to assistive technology.
    </li>
    <li>
      <strong>Loading container.</strong> Wrap skeletons in a container with{" "}
      <code>aria-busy=&quot;true&quot;</code> while loading — that's the wrapping
      container's responsibility, not Skeleton's, since it has no way to know when
      loading actually finishes.
    </li>
    <li>
      <strong>Announcing completion.</strong> Announce the swap to real content via a
      live region elsewhere on the page.
    </li>
  </ul>
</A11yCallout>
