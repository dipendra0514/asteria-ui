## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";

<Textarea placeholder="Write a message..." />
```

Unlike [Input](/docs/components/input), Textarea has no icon slots in its
spec, so it's a single unwrapped `<textarea>` — no bordered wrapper div
needed. Pair it with [Field](/docs/components/field) for a label and
helper/error text.

## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Role.</strong> Native <code>&lt;textarea&gt;</code>, so{" "}
      <code>role=&quot;textbox&quot;</code> with an implicit multiline hint is

    </li>

    <li>

    </li>
    <li>

    </li>
  </ul>
