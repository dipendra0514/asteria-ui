
### With icon

`leadingIcon` accepts any element and sizes it automatically to match the
button — 16px at sm/md, 20px at lg/xl. It's a decorative slot: the icon is
marked `aria-hidden` for you.

<ButtonWithIcon />

### States

`loading` shows a spinner, sets `aria-busy`, and disables the button —
independent of the `disabled` prop, so a button can be disabled without
being in a loading state.

## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Role.</strong> Native <code>&lt;button&gt;</code>, so{" "}
      <code>role=&quot;button&quot;</code> and keyboard activation (Enter/Space) come from
      the browser, not manual ARIA.
    </li>
    <li>
      <strong>Focus.</strong> Visible <code>glow-focus</code> ring on Tab, via{" "}
      <code>focus-visible</code> — never shown on a pointer click.
    </li>
    <li>
      <strong>Disabled.</strong> The native <code>disabled</code> attribute prevents all
      interaction, including from <code>loading</code>.
    </li>
    <li>
      <strong>Loading.</strong> <code>aria-busy=&quot;true&quot;</code> announces the busy
      state to screen readers while the spinner is visible.
    </li>
  </ul>
</A11yCallout>
