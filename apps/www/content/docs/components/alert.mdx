## Accessibility

<A11yCallout>
  <ul>
    <li>
      <strong>Role is variant-dependent.</strong>{" "}
      <code>warning</code>/<code>error</code> use{" "}
      <code>role=&quot;alert&quot;</code> (assertive, interrupting) —{" "}
      <code>info</code>/<code>success</code> use{" "}
      <code>role=&quot;status&quot;</code> (polite). This is computed automatically from
      the <code>variant</code> prop, not something you set yourself.
    </li>
    <li>
      <strong>Icon.</strong> Decorative, <code>aria-hidden</code>.
    </li>
    <li>
      <strong>Dismiss button.</strong> <code>aria-label=&quot;Dismiss&quot;</code>.
    </li>
  </ul>
</A11yCallout>
